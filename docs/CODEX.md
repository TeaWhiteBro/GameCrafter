# Executing with a coding agent

Open the GameCrafter repository in your coding agent and use [the task template](../examples/prompts/agent_task.txt). Replace the brief, run directory and optional references. Configure native tools and process credentials using [README.md](../README.md).

The agent must read [AGENTS.md](../AGENTS.md), [AGENT_PROTOCOL.md](../AGENT_PROTOCOL.md) and [WORKFLOW.md](WORKFLOW.md), operate the native tools, inspect current source and rendered evidence, and complete required gates. Read [REPRODUCING.md](REPRODUCING.md) for input modes and acceptance. An agent label does not imply a new process or parallel scheduler; specialist roles share artifact contracts and may use one model endpoint.

Routine repair stays with the executing agent: diagnose the layer, preserve paid state, measure affected scope and resume. Source or structural failures are not solved by automatic exposure patches. If the machine lacks native tools, provider access or a display, report the exact remaining requirement and do not claim acceptance.
