Fresh production and scoped recovery

New runs generate new case content. Public PBR downloads and installed UE motions are declared dependencies. An explicit provided-mode replacement can keep the surrounding world while affected consumers are revalidated. Same-run resume retains paid task IDs and valid artifacts.

Evidence-driven repair

The executing agent handles structural diagnoses. Only bounded exposure / sky / fog patches are automatically applied by the CLI. Unchanged rejected images cannot be resampled for approval; three distinct refused preflights require a source-bound repair plan with hashed verification evidence before another capture/review.

Software boundaries

Tripo provides source geometry. Blender prepares characters and builds detailed / structural scenes. UE retargets installed motion, implements gameplay and renders the world. Model planning, model review and deterministic validation are separate responsibilities.

Current scope

Upright humanoids, one melee Boss and connected exploration. The standard profile has six 360-frame sequences at 640 × 360. A source release and its offline tests are distinct from a new clean-machine integrated game acceptance.
