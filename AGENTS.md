- Construct detailed geometry and structural whitebox together. Check actual support, portals, resource usage and route clearance before UE. Particles or exposure cannot repair structure.

- After three distinct refused environmental reviews, complete the source-bound repair plan with current hashed evidence and full issue coverage. Diagnose shared causes, batch related fixes and stop optional polish after hard requirements pass.
- Preserve every full requested camera/activity probe, real gameplay/contact, valid facing fault controls, same-session switching, independent calibration and all-frame native/export checks. First-person owner hiding is intentional.
- Declare helper dependencies in implementation.py. Use isolated projects and artifact revisions. Never mutate accepted or upstream committed outputs downstream.
- Final release requires matching replay and actual responsive launcher observation where a display is available. Report unverified steps and observed warnings; fixed-step simulation does not establish game FPS.
- Run relevant regression tests. Source publishing also requires full offline tests from a clean exported tree and source/path/credential review. Do not publish remotely without user authorization.
- Code, prompts and primary documentation are English. Maintain the matching README.zh-CN.md. Public naming is GameCrafter; include only current framework contracts and capabilities.
